# Evidence, batching, and performance

Quick limits broad discovery; Deep (default) explores important subsystems and enriches
significant modules; Exhaustive covers all relevant indexed modules without indiscriminate
raw-file crawling. Release detailed context after each module packet and retain only compact
facts. Batch independent deterministic reads, but keep HomeGraph calls serial per index.

Direct reads are for descriptors, resources, docs, configs, and named unresolved questions.
Do not perform literal full-file review of every file. Redact secrets, tokens, signing
material, credentials, personal data, and raw graph responses from state and generated docs.
