# Project SPEC Content Contract

`project_spec_write` owns canonical rendering and validation. Supply concise content for these areas:

1. Project overview and graph-analysis metadata, including exact repository/HomeGraph revisions when available.
2. Repository structure, modules, boundaries, and ownership.
3. Entry points and evidence-backed runtime flows.
4. Interfaces, contracts, state, persistence, and external dependencies.
5. Change guidance, impact/risk hotspots, build, configuration, and testing.
6. Existing documentation, conventions, sensitive areas, uncertainties, and generation metadata.

Use paths, symbols, relationships, confidence, and compact evidence references. Do not paste raw source or tool output, duplicate sections, or include proposed feature design.
