Build a deterministic ProjectSpec workspace inventory before semantic analysis. The analysis is confined to the opened workspace and never scans its parents, siblings, or drive root. Use once per documentation run to detect single-repository, monorepo, Git-submodule, Repo-tool, ArkTS/DevEco, and OpenHarmony component boundaries; enumerate physical modules/build units; resolve local dependency candidates; and measure owned source scale. The full normalized JSON is written to docs/.projectspec/workspace-inventory.json while the tool returns only a compact summary. This tool does not infer business capabilities or replace Homegraph semantic queries.
